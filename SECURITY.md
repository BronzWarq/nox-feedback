# Безопасность / Security

## Русский

Не создавайте публичный Issue, если проблема может раскрыть токены, ключи, персональные данные или предоставить чужой доступ.

Для публичного описания используйте только обезличенные данные. Удалите секреты из снимков экрана и журналов.

В Issues запрещено публиковать содержимое `.env`, токены Telegram и Twitch, API-ключи, пароли и коды авторизации.

## English

Do not open a public issue if the report may expose tokens, keys, personal data, or unauthorized access.

Use anonymized information in public reports. Remove secrets from screenshots and logs.

Never publish `.env` contents, Telegram or Twitch tokens, API keys, passwords, or authorization codes in an issue.
