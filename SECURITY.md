# Сообщения о безопасности

Не создавайте публичный Issue, если проблема может раскрыть токены, ключи, персональные данные или позволить получить чужой доступ.

Для публичного описания используйте только обезличенные данные и удалите секреты из снимков экрана и журналов.

В обычных Issues запрещено публиковать содержимое `.env`, токены Telegram и Twitch, API-ключи, пароли и коды авторизации.
